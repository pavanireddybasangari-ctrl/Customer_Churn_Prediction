# Customer Churn Prediction

## 📌 Project Overview

This project uses Machine Learning to predict whether a customer is likely to churn.

The application is built using Python, Pandas, Scikit-learn and Streamlit.

## 🤖 Machine Learning Models

- Logistic Regression
- Random Forest

The models are evaluated using accuracy, and the better-performing model is selected for prediction.

## 📊 Features

- Customer churn prediction
- Churn probability
- Customer risk level
- Feature importance visualization
- Interactive Streamlit interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

## 📂 Project Files

- `app.py` — Streamlit application
- `churn_prediction.py` — model training and preprocessing
- `churn_model.pkl` — trained machine learning model
- `model_features.pkl` — model feature information
- `customer_churn.csv` — dataset

## 🎯 Objective

To build a Machine Learning application that helps identify customers who may be likely to leave a service.
